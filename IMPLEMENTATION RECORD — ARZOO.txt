GRAPH INGESTION IMPLEMENTATION (DAY 3)

File:
app/ingestion/graph_ingestor.py

Design Principles:

✔ Single-transaction ingestion
✔ MERGE-based upserts
✔ Idempotent writes
✔ Full rollback on failure

Ingestion Flow:

1. Upsert Act node (MERGE)
2. Upsert Section nodes (MERGE)
3. Create HAS_SECTION relationships (MERGE)
4. Entire operation wrapped in one transaction

Atomicity Guaranteed:

If any failure occurs during insertion,
the entire transaction is rolled back.

No partial writes possible.
